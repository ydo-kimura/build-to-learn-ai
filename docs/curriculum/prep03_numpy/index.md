## 1. Python のリストと NumPy 配列を比べる

Prep 2 では、複数の値をリストへまとめました。

```python
numbers = [1, 2, 3]

print(type(numbers))
print(numbers * 2)
```

```text
<class 'list'>
[1, 2, 3, 1, 2, 3]
```

リストに `* 2` を使うと、各数値が2倍になるのではなく、リストの並びが2回繰り返されます。

同じ値から NumPy 配列を作ります。

```python
array_numbers = np.array(numbers, dtype=np.int64)

print(type(array_numbers))
print(array_numbers * 2)
print(array_numbers.dtype)
```

```text
<class 'numpy.ndarray'>
[2 4 6]
int64
```

NumPy 配列に `* 2` を使うと、各要素が2倍になります。このように、NumPy は複数の数値へ同じ計算をまとめて適用できます。

`ndarray` は「N-dimensional array」、つまりN次元配列を表す NumPy の型です。`dtype` は配列内の要素のデータ型です。ここでは `dtype=np.int64` を指定したため、64ビット整数として格納されています。

リストと NumPy 配列は、どちらか一方が常に優れているわけではありません。名前の一覧のように、値を順番に保持するだけならリストで十分な場合があります。多くの数値へ同じ計算を適用したり、行と列を持つデータを扱ったりするときに、NumPy 配列が役立ちます。

## 2. 次元と形を確認する

この Prep では、4人の学習記録を使います。

| 学習者 | 学習時間 | 挑戦回数 | 得点 |
| ------ | -------: | -------: | ---: |
| Aoi    |        2 |        1 |   60 |
| Ren    |        4 |        2 |   72 |
| Mio    |        6 |        3 |   84 |
| Sora   |        8 |        4 |   96 |

1行が1人の学習者、1列が1つの測定項目を表します。列は左から、学習時間、挑戦回数、得点です。

### 一次元配列

得点だけを横に並べた配列を作ります。

```python
scores = np.array([60, 72, 84, 96], dtype=np.int64)

print(scores)
print(scores.ndim)
print(scores.shape)
```

```text
[60 72 84 96]
1
(4,)
```

`ndim` は次元の数です。`scores` は値が1方向に並ぶ一次元配列なので、`ndim` は `1` です。

`shape` は、各次元にいくつの要素があるかをタプルで表します。`(4,)` は「1つの次元に4要素ある」という意味です。`4` の後ろにあるカンマは、`(4,)` が整数ではなく、要素が1つのタプルであることを示します。

### 二次元配列

表の数値を、4行3列の配列にします。

```python
records = np.array(
    [
        [2, 1, 60],
        [4, 2, 72],
        [6, 3, 84],
        [8, 4, 96],
    ],
    dtype=np.int64,
)

print(records)
print(records.ndim)
print(records.shape)
```

```text
[[ 2  1 60]
 [ 4  2 72]
 [ 6  3 84]
 [ 8  4 96]]
2
(4, 3)
```

`records` は行と列の2方向を持つため、`ndim` は `2` です。`shape` の `(4, 3)` は「4行3列」を表します。

- 4行は Aoi、Ren、Mio、Sora の4人
- 3列は学習時間、挑戦回数、得点の3項目

`shape` の値を見たときは、単に「4と3」と読むのではなく、その数が何の件数なのかを元のデータと照らし合わせます。

### 4行1列も二次元

得点を4行1列にすると、次の形になります。

```python
scores_column = np.array(
    [
        [60],
        [72],
        [84],
        [96],
    ],
    dtype=np.int64,
)

print(scores_column)
print(scores_column.ndim)
print(scores_column.shape)
```

```text
[[60]
 [72]
 [84]
 [96]]
2
(4, 1)
```

`(4, 1)` は4行1列です。列が1つしかなくても、行と列の2方向を持つため二次元配列です。

同じ4つの得点でも、`(4,)` は一次元、`(4, 1)` は二次元です。値の数だけでは、配列の次元や形は決まりません。値をどの構造で並べたかまで確認します。

## 3. 行、列、範囲、1つの値を選ぶ

NumPy のインデックスは、Python のリストと同じく `0` から始まります。二次元配列では、角括弧の中を `行, 列` の順に指定します。

### 1行を選ぶ

```python
first_learner = records[0]

print(first_learner)
print(first_learner.ndim)
print(first_learner.shape)
```

```text
[ 2  1 60]
1
(3,)
```

`records[0]` は0番目の行、つまり Aoi の学習時間、挑戦回数、得点を選びます。元の `records` は二次元ですが、1行を取り出した結果は3要素の一次元配列です。

### 1列を選ぶ

```python
study_hours = records[:, 0]

print(study_hours)
print(study_hours.ndim)
print(study_hours.shape)
```

```text
[2 4 6 8]
1
(4,)
```

コロン `:` は、その位置の全範囲を表します。`records[:, 0]` は「すべての行から、0番目の列を選ぶ」という意味です。結果は4人分の学習時間です。

### 行の範囲を選ぶ

```python
first_two_learners = records[:2, :]

print(first_two_learners)
print(first_two_learners.ndim)
print(first_two_learners.shape)
```

```text
[[ 2  1 60]
 [ 4  2 72]]
2
(2, 3)
```

`records[:2, :]` は「先頭から2行目の直前まで」と「すべての列」を選びます。Aoi と Ren の2行が残るため、形は `(2, 3)` です。

### 1つの値を選ぶ

```python
mio_score = records[2, 2]

print(mio_score)
print(np.ndim(mio_score))
print(np.shape(mio_score))
```

```text
84
0
()
```

`records[2, 2]` は2番目の行、2番目の列、つまり Mio の得点 `84` を選びます。行や列としてではなく1つの値を選んだため、結果は配列ではなく NumPy のスカラー値です。

スカラーは0次元で、`np.shape()` の結果は空のタプル `()` になります。「形が壊れた」のではなく、行や列の広がりを持たない1つの値になったことを表します。

## 4. 配列を集計する

NumPy のメソッドを使うと、配列に含まれる数値を集計できます。

```python
print(records.min())
print(records.max())
print(records.mean())
```

```text
1
96
28.5
```

- 最小値は、配列全体で最も小さい挑戦回数 `1`
- 最大値は、配列全体で最も大きい得点 `96`
- 平均値は、12個の数値をすべて足して12で割った `28.5`

NumPy は正しく計算しています。しかし、`28.5` は学習時間、挑戦回数、得点という単位の異なる値を混ぜた平均です。「平均的な学習記録が28.5」と解釈しても、何が28.5なのか説明できません。

計算できることと、その計算がデータの意味から見て有用であることは別です。集計するときは、どの値をまとめたのか、その値の単位や役割を一緒に確認します。

## 5. `axis` を指定して集計する

二次元配列では、`axis` を指定して集約する軸を選べます。「`axis=0` は列、`axis=1` は行」と結果だけを暗記すると、配列の形が変わったときに混乱しやすくなります。

次の2点を組にして確認します。

1. どの軸に沿って値を集約したか
2. 集約した後、何ごとの結果が残ったか

### `axis=0`: 行をたどって集約する

```python
column_means = records.mean(axis=0)

print(column_means)
print(column_means.shape)
```

```text
[ 5.   2.5 78. ]
(3,)
```

入力 `records` の形は `(4, 3)` です。`axis=0` では、4行を上から下へたどって値を集約します。行の軸が集約され、3列それぞれの結果が残ります。

- 0番目の値 `5.0`: 学習時間の平均 `(2 + 4 + 6 + 8) / 4`
- 1番目の値 `2.5`: 挑戦回数の平均 `(1 + 2 + 3 + 4) / 4`
- 2番目の値 `78.0`: 得点の平均 `(60 + 72 + 84 + 96) / 4`

入力は `(4, 3)`、出力は `(3,)` です。4人分の行をまとめた結果、3項目分の値が残りました。列ごとに同じ意味と単位の値を平均しているため、各結果を説明できます。

### `axis=1`: 列をたどって集約する

```python
row_means = records.mean(axis=1)

print(row_means)
print(row_means.shape)
```

```text
[21. 26. 31. 36.]
(4,)
```

`axis=1` では、各行について3列を左から右へたどって値を集約します。列の軸が集約され、4行それぞれの結果が残ります。

- 0番目の値 `21.0`: Aoi の `(2 + 1 + 60) / 3`
- 1番目の値 `26.0`: Ren の `(4 + 2 + 72) / 3`
- 2番目の値 `31.0`: Mio の `(6 + 3 + 84) / 3`
- 3番目の値 `36.0`: Sora の `(8 + 4 + 96) / 3`

入力は `(4, 3)`、出力は `(4,)` です。3列をまとめた結果、4人分の値が残りました。

ただし、この4つの平均は学習時間、挑戦回数、得点を混ぜています。NumPy の軸の動きを確認する計算例にはなりますが、学習者を評価する指標としては意味がありません。値が表示されたことだけを成功とせず、「何をまとめた値なのか」を説明できるか確認してください。

## 6. 特徴量 `X` と目的変数 `y`

機械学習では、予測の手がかりとして使う列を特徴量、予測したい列を目的変数と呼びます。

この例では、学習時間と挑戦回数から得点を予測すると考えます。

- 特徴量 `X`: 学習時間と挑戦回数
- 目的変数 `y`: 得点

```python
X = records[:, :2]
y = records[:, 2]

print(X)
print(X.ndim)
print(X.shape)

print(y)
print(y.ndim)
print(y.shape)
```

```text
[[2 1]
 [4 2]
 [6 3]
 [8 4]]
2
(4, 2)
[60 72 84 96]
1
(4,)
```

`X` は4人について2つの特徴量を持つため、4行2列の二次元配列です。`y` は4人それぞれに1つの得点を持つため、4要素の一次元配列です。

scikit-learn では、多くの場合、特徴量 `X` を「行がサンプル、列が特徴量」の二次元データとして渡し、目的変数 `y` を各サンプルに対応する一次元データとして渡します。

行数が一致していることも確認します。

```python
print(X.shape[0])
print(y.shape[0])
print(X.shape[0] == y.shape[0])
```

```text
4
4
True
```

`X` の0番目の行と `y` の0番目の値は、どちらも Aoi の記録です。同じように、各行と各目的値が同じ学習者を指します。行数が違うと、どの特徴量とどの目的値が対応するのか決められません。
